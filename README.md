# 🏛️ Sistema de Ofícios - Online

Sistema completo de controle de numeração de ofícios com armazenamento de documentos Word na nuvem.

## ✅ Status do Projeto

**CONFIGURAÇÃO CONCLUÍDA!**

- ✅ Banco de dados PostgreSQL no Supabase (São Paulo, Brasil)
- ✅ Storage de documentos Word na nuvem
- ✅ Numeração única garantida (001-999 por ano)
- ✅ Multi-usuário em tempo real

## 🚀 Como Usar

### Passo 1: Substituir o `index.html`

Você recebeu o código completo no email **vhbernardo@yahoo.com.br**. 

1. Abra o arquivo `index.html` neste repositório
2. Substitua todo o conteúdo pelo código do email
3. Faça commit das alterações

### Passo 2: Ativar GitHub Pages

1. Vá em **Settings** → **Pages**
2. Em "Source", selecione **main branch**
3. Clique em **Save**
4. Aguarde 1-2 minutos

### Passo 3: Acessar o Sistema

Acesse: **https://vhbernardo11.github.io/sistema-oficios**
